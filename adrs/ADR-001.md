## Context
Synchronous REST microservices are leading to cascading timeouts during burst traffic.

## Decision
Implement an asynchronous event bus using Kafka for all cross-service state propagation.

## Consequences

### Positive
- Decoupled services
- High throughput
- Replayable event log

### Negative
- Eventual consistency complexity
- Operational overhead of Kafka clusters
