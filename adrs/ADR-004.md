## Context
Autonomous AI agents need secure, standardized tool execution and database introspection.

## Decision
Adopt Anthropic Model Context Protocol (MCP) as the unified interface for system tools.

## Consequences

### Positive
- Interoperable tool registry
- Granular sandboxed execution

### Negative
- Evolving specification requires ongoing maintenance
